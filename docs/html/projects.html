Distributed Fine-Tuning of an 8B Model

Summary

Profiled and optimized distributed training of an 8B-parameter transformer model on dual NVIDIA A100 GPUs, focusing on communication overhead, memory fragmentation, and scaling limits under constrained hardware.

Project Report
Project GitHub

Key Contributions

  • Analyzed ZeRO-2 vs ZeRO-3 communication overhead
  • Identified scaling bottlenecks via NCCL trace analysis
  • Quantified memory fragmentation impact on batch size
  • Improved GPU utilization through configuration tuning

Impact

  • Demonstrated tradeoffs between parameter sharding and throughput
  • Presented findings to the University of Basel HPC research group (Their homepage)

Technologies

  • Python
  • PyTorch
  • DeepSpeed
  • CUDA
  • NCCL
  • Slurm
  • A100 GPUs

Shortest Path Algorithms on Social and Grid Graphs

Project Overview

Compared Breadth-First Search, Dijkstra's algorithm, and A* with classical and embedding-based heuristics across real-world social networks and grid graphs. Benchmarked how graph topology, density, and heuristic quality affect search performance.

Project Report
Project GitHub

Key Findings

  • Graph structure influences algorithm exploration and runtime
  • Heuristic quality strongly affects A* efficiency on grid graphs

Technologies

  • C#
  • SNAP datasets
  • Custom benchmarking framework
